# SITE-SELFCARE

Este site denominado SelfCare foi um desafio proposto pela empresa Vai Na Web que ministrou o curso de Desenvolvimento Web em que cursei em 2024. Foi satisfatório realizar este desafio, pois, tive a oportunidade de reforçar minhas habilidades e conhecimentos adquiridos durante o curso até o momento. Foi prazeroso participar da comunidade de alunos da Vai Na Web, tanto pelo aprendizado como pelo compartilhamento de conhecimento entre nós, alunos.
